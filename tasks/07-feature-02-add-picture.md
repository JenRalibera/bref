## User Story

En tant qu'utilisateur,
je veux ajouter une image à une note par copier-coller,
afin d'associer un élément visuel à mon information.

## Critères d'acceptation

AC1 — Coller une image

L'utilisateur peut coller une image dans une note.

AC2 — Image facultative

Une note peut être enregistrée sans image.

AC3 — Une note avec image

Une note peut contenir son texte ainsi qu'une image.

AC4 — Enregistrement

Quand l'utilisateur clique sur Enregistrer,
alors l'image collée est conservée avec la note.
