## User Story

En tant qu'utilisateur,
je veux consulter les notes associées au site que je visite,
afin de retrouver les informations que j'ai enregistrées pour ce site.

## Critères d’acceptation

AC1 — Notes du site

Étant donné que le site courant possède des notes,
quand l'utilisateur ouvre l'extension,
alors seules les notes associées à ce site sont affichées.

AC2 — Plusieurs notes

Étant donné que le site possède plusieurs notes,
alors toutes les notes associées à ce site sont affichées.

AC3 — Aucune note

Étant donné que le site courant ne possède aucune note,
quand l'utilisateur ouvre l'extension,
alors aucune note n'est affichée.

AC4 — Navigation

Étant donné que l'utilisateur navigue vers un autre site,
quand il consulte l'extension,
alors les notes affichées correspondent au nouveau site.

AC5 — Extension désactivée

Étant donné que l'extension est désactivée,
alors les notes existantes restent consultables.
