## User Story

En tant qu'utilisateur,
je veux modifier une note existante,
afin de mettre à jour son contenu.

## Critères d'acceptation

AC1 — Accéder à l'édition

Étant donné qu'une note existe,
quand l'utilisateur choisit Modifier,
alors il accède à l'édition de cette note.

AC2 — Modification

L'utilisateur peut modifier le contenu de la note.

AC3 — Enregistrement

Quand l'utilisateur clique sur Enregistrer,
alors les modifications sont enregistrées.

AC4 — Pas d'enregistrement automatique

Tant que l'utilisateur n'a pas cliqué sur Enregistrer,
les modifications ne sont pas enregistrées.

AC5 — Extension désactivée

Si l'extension est désactivée, l'action Modifier n'est pas accessible.
