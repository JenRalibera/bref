# User Story

En tant qu'utilisateur,
je veux pouvoir accéder à l'extension depuis mon navigateur,
afin de pouvoir utiliser ses fonctionnalités.

# Critères d’acceptation

AC1 — Extension accessible

Étant donné que l'extension est installée dans le navigateur,
quand l'utilisateur consulte son navigateur,
alors il peut accéder à l'extension depuis l'interface du navigateur.

AC2 — Ouverture de l'extension

Étant donné que l'extension est accessible,
quand l'utilisateur clique sur son icône,
alors l'interface de l'extension s'ouvre.
